# Screenshots for the Chrome Web Store listing

Synthetic screenshots generated by driving the in-repo demo entry
(`src/dashboard/demo/`) through headless Chrome at 1280×800. Curated
fixture: 30 tabs across 2 Chrome windows, four tab groups (Shipping,
Reading, Read later, Errands), realistic titles + favicons.

| File                  | Captures                                                                                                          |
| --------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `01-by-window.png`    | Headline shot. "By window" view with the diagnostic counter, search bar, group chips, and favicon column visible. |
| `02-by-tab-group.png` | "By tab group" view — sections labelled by Chrome group name (Reading, Read later, Errands).                      |
| `03-by-domain.png`    | "By domain in url" view — sections labelled by domain, sorted by tab count.                                       |

## Regenerate

```bash
# 1. Start the dev server with the demo entry
pnpm vite --port 5174 --strictPort

# 2. From another shell:
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
for VIEW in window tabgroup domain; do
  TMPDIR=$(mktemp -d)
  timeout 25s "$CHROME" \
    --headless=new \
    --disable-gpu --hide-scrollbars --no-sandbox \
    --no-first-run --no-default-browser-check --disable-extensions \
    --window-size=1280,800 \
    --virtual-time-budget=5000 \
    --screenshot=docs/screenshots/${VIEW}.png \
    --user-data-dir="$TMPDIR" \
    "http://localhost:5174/src/dashboard/demo/index.html?view=${VIEW}"
  rm -rf "$TMPDIR"
done
```

The `?view=` query param is read by `main.demo.tsx`; it clicks the
matching radio after mount.

## Suggested manual supplements

Two views the synthetic shots can't capture cleanly without scripted
interaction:

- **Bulk-select with the Close? + Add to group ▾ action panel visible** —
  check ≥2 rows in any section, then screenshot.
- **Add-to-group picker open** — click `Add to group ▾`, then screenshot
  while the dropdown is showing.

Take these against your real Chrome (extension loaded + ≥10 real tabs) for
the most authentic look.
